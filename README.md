# 몽글몽글 한글 놀이터

3~4세 학습 수준을 고려한 한글 학습 프로그램 초안입니다.
생활 낱말 1개, 동물 20개, 과일 22개, 채소 20개, 공공시설 20개, 탈것 20개, 바다생물 20개로 총 123개의 낱말을 제공합니다. 과일에는 기존 사과·바나나와 새 낱말 20개가 포함됩니다.

## 열기
`dist/index.html`을 브라우저에서 열면 사용할 수 있습니다. 배포 링크는 이 대화에 제공됩니다.

## 사용하기
1. 전체·생활·동물·과일·채소·공공시설·탈것·바다생물 분류에서 낱말을 고릅니다.
2. 보고 읽기, 따라쓰기, 빈칸 넣기 활동을 선택합니다.
3. 글자 크기를 40~80px로 조절합니다. 빈칸 넣기에서는 비워 둘 글자 위치도 선택할 수 있습니다.
4. 따라쓰기 영역은 마우스, 터치, 펜으로 쓸 수 있습니다. 획순 안내나 자동 필기 채점은 포함하지 않습니다.
5. A4 학습지 미리보기 → 인쇄 / PDF 저장으로 현재 낱말의 학습지를 만듭니다. 용지 A4, 배율 100%, 브라우저 머리글·바닥글 해제를 권장합니다. 인쇄물에는 답이나 화면 필기가 들어가지 않습니다.

설정은 현재 브라우저에 저장됩니다. 필기와 정답은 새로고침하면 초기화됩니다. 낱말 듣기는 기기에 설치된 한국어 음성에 따라 동작합니다.

## 사진
생활·동물·과일·채소·탈것·바다생물 사진 103장은 image_gen 도구로 생성한 AI 이미지입니다. 전남 공공시설 사진 20장은 실제 촬영 사진으로, dist/facility-sources.json에 출처를 기록했습니다. AI 사진의 프롬프트는 IMAGE-PROMPTS.json과 VEHICLE-IMAGE-PROMPTS.json에 기록했습니다.

## 확인
check.mjs에서 123개 사진 연결, 모든 빈칸 위치의 오답·정답·재시도, 80px 글자 설정, 따라쓰기 초기화, 분류별 이전·다음 이동과 세 활동의 인쇄 HTML 및 인쇄 호출을 검사했습니다. 이 검사는 실제 브라우저의 최종 인쇄 레이아웃을 보증하지 않습니다.

공공시설 20개는 전남 소재 실제 시설 사진입니다. 출처·촬영시점·저작자·라이선스는 dist/facility-sources.json과 사진 출처 화면, A4 학습지에 표시합니다. 사진은 촬영 당시 모습이며 최신 외관을 보장하지 않습니다.

## 실제 소리
동물과 탈것 화면의 소리 듣기 버튼으로 실제 녹음 자료를 최대 6초 들을 수 있습니다. 자동 재생 없이 시작하며 기본 음량은 30%입니다. 멈추기와 음량 조절을 지원하고, 낱말·활동 변경 및 인쇄 때 소리가 멈춥니다. 녹음의 설명과 저작자·출처·이용 조건은 화면과 sound-sources.html, sound-sources.json에 기록했습니다. 낱말 읽기 음성과 실제 녹음은 별도 버튼입니다.

음원의 MP3 디코딩과 무음 여부를 FFmpeg로 검사했습니다. 실제 브라우저의 소리 출력과 인쇄 최종 배치는 브라우저 제어 도구 오류로 확인하지 못했습니다.
v1.0.1 (2026.10.07): 탈것 20종을 한국 현장 녹음·국내 제공기관 음원으로 교체. 녹음 지역 미표시와 전차/보트/킥보드 예시 음원은 항목별로 설명.
v1.1.0 (2026.10.08): 바다생물 20종과 실사 AI 사진 추가. 총 123개 낱말, 8개 분류. 프롬프트는 SEA-IMAGE-PROMPTS.json에 기록.
