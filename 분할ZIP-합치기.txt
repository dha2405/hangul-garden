분할 ZIP 합치기 안내
각 ZIP은 독립적으로 압축 해제할 수 있으며 32MB 미만입니다.
소스 ZIP과 자료 ZIP 전체를 다운로드한 뒤 모두 같은 폴더에 압축을 푸세요.
모든 ZIP에는 hangul-garden/ 폴더 구조가 들어 있습니다. 같은 이름의 폴더는 병합해 주세요.
ZIP마다 별도 폴더를 만드는 옵션은 끄거나, 각 ZIP 안의 hangul-garden 내용을 하나로 합쳐 주세요.
소스 ZIP만으로 코드 확인이 가능합니다. 사진·음원을 모두 표시하려면 자료 ZIP도 모두 필요합니다.
실행 방법은 hangul-garden/START-HERE-KO.txt를 확인하세요.
설치된 의존성, Git 이력, 빌드·캐시, .env, 비밀 키, 실제 학생 기록은 포함하지 않습니다.
